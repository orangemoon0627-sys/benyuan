# 本源（Benyuan）：用 AI 多模态从行为痕迹倒推精神本源

**本源是什么？** 本源是用 AI 多模态做精神分析的自我探索工具：它收集你的歌单、照片、收藏、文字和行为痕迹，从行为痕迹「倒推」你的精神本源，生成一份会生长的精神星图报告。

**在线入口**：https://benyuan.orangemoon.tech

## 它解决什么问题

- 人格测试（MBTI 等）是「对应」：先有类型框架再把你放进去，结论先于证据；本源是「倒推」：先看你留下的东西，结论长在证据上。
- 算命（紫微斗数、八字十神）给你的是地图，不是答案——它说方位，说不清你这片地的具体地貌。
- 结果不是一次性快照：同一个人两次来，星体可能一样，但报告不该一样。一份会生长的档案，才配叫在看当下的人。

## 它是怎么做的

1. **收集线索**：歌单看情绪底色（声音气候），照片和收藏看审美动机，文字看自我投射。这些是你「留」下来的自己，不是你说出来的自己。
2. **情境剧场**：把人放进几轮具体情境看怎么选，照见形式逻辑——人在虚构情境里的动作比「我觉得我很勇敢」更真实。
3. **精神星图**：把线索和选择拼成一份报告，只保留固定星体当锚点，不让模型发明讨喜的身份标签。

## 和其他方案有什么不同

| 维度 | 本源 | 算命 | MBTI |
| --- | --- | --- | --- |
| 核心逻辑 | 从行为痕迹「倒推」 | 用固定数据「对应」命盘 | 用量表「对应」类型 |
| 结论与证据的关系 | 结论长在证据上 | 结论先于证据 | 结论先于证据 |
| 两次结果 | 星体可能一样，报告会生长 | 命盘相同，判词基本固定 | 同一类型，描述基本相同 |
| 使用方式 | 先看你的歌单、照片、文字 | 报生辰、排盘 | 做选择题量表 |
