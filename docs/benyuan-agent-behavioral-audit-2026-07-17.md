# 本源智能体行为认知审计（2026-07-17）

## 目标

本源不是临床诊断工具。它的有效目标是：从自陈选择、审美材料、社交表达与四轮情境行为中，给出证据可追溯、能区分状态与稳定倾向、允许反证的精神结构阅读，并以非病理化方式形成高质量正反馈。

## 已确认事实

1. Part 1 当前由 9 组固定选项题、1 组时间分配题和 3 组多模态上传组成；剧场固定为 4 轮、每轮 4 个选项。
2. 固定选项在本地映射精神信号；音乐、社交动态和照片由多模态 Agent 分析；剧场负责补采样前半程缺失或冲突的向量；星图 Agent 汇总全部证据。
3. 音乐只允许使用公开歌曲/艺术家元数据补全。社交动态与私人照片不进行公网搜索、账号识别或反向搜图。
4. 2026-07-17 的选项覆盖审计中，所有 9 组固定选项题均已做到：每个选项至少映射一个标准精神信号，同题内没有两项完全落到相同的标准信号集合。
5. 2 万组均匀随机合法答卷的校准烟测显示明显分型先验：`lone_seeker` 34.42%，`black_hole_event_horizon` 19.44%，而 `melancholic_poet`、`rational_builder`、`existential_wanderer` 均低于 1%。这不是用户真实分布，但足以证明当前规则对少数标签存在可达性偏置。

## 本轮已修复

### 多模态证据层

新增可选 `behavioral_signals`：每条包含标准信号、支持/反证、0-1 置信度、时间范围、可见证据锚点和备选解释。后续精神元数据优先读取该结构；只有旧结果没有结构化信号时才回退到关键词解析。

多模态缓存协议同步升级到 `v4-behavioral-evidence-2026-07-17`，旧缓存不会绕过新分析结构。

收益：单一颜色、单首歌或一句动态不再仅凭自由文本关键词升级为稳定人格；“另一种合理解释”能够随证据进入后续 Agent，而不是在归一化时丢失。

### 固定题向量

补齐原先无标准信号或同题难区分的选项，重点覆盖作品投射、关系距离、意义取向、情绪容器和行动入口。

收益：题目可见文案不变，但后台向量不再出现空映射或同题完全同构。

### 剧场补采样

四轮内部向量固定绑定：行动入口、关系距离、欲望与边界、动机/时间感/潜在防御。后端归一化会保留模型生成的行为方向，同时补上缺失的轮次采样域。

收益：四轮不只承担剧情推进，还能补足“后退是边界还是回避、等待是耐心还是难以启动”这类动机差异。

同时修复 fast profile 原先只生成场景母题、仍复用固定 16 个选项的问题。新的 compact seed 会生成 4 轮场景与 4×4 个个性化选项、向量和选中回声；后端逐轮校验，单轮结构不合法时只回退该轮固定骨架。

### 正反馈

星图 Prompt 改为“适应性功能 -> 已形成能力 -> 当前代价 -> 更自由的选择”。正反馈必须绑定证据，不使用万能赞美，不浪漫化痛苦或回避。

收益：用户得到的是可使用的自我理解，而不是漂亮但不可核验的夸奖。

## 暂不直接修改

### 主星体权重重标定

当前分型偏置已确认，但没有足够的人工标注真值。直接追求十类均匀会把统计外观误当成心理有效性，因此本轮不修改生产权重。

进入重标定前至少需要：

- 30-50 份覆盖不同输入密度的盲测样本；
- 每份由用户本人和至少 2 名独立评审评价“主标签贴合度、证据命中度、意外但准确度”；
- 同一用户间隔 7-14 天复测，区分稳定结构与当下状态；
- 反事实测试：只替换歌单、只替换照片、只改变一轮剧场选择，检查变化是否局限在相关维度；
- 记录第一名与第二名原型的分差，低分差结果不做过度确定表达。

## 建议发布门槛

- 核心判断证据可追溯率 >= 90%；
- 单一证据触发稳定人格强结论的比例 = 0；
- 同输入重复生成的核心结构一致率 >= 85%；
- 同标签不同输入时，肖像、张力、路径和推荐有可解释差异；
- 用户“被说中”评分中位数 >= 4/5；
- 用户“空泛夸赞”或“生搬素材”反馈 <= 10%；
- 所有诊断化、命运化、创伤推断样本必须为 0。
